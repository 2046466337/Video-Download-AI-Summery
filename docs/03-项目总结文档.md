## 4. 关键实现：站点适配

平台反爬策略各异，`yt-dlp` 官方解析器在部分站点会失效。项目坚持「不改 yt-dlp 源码」，把适配逻辑放在独立的 `*_adapter.py` 中，通过 `ydl_service.py` 的域名判断分流。

### 4.1 哔哩哔哩（`bilibili_adapter.py`）

- **问题**：WAF 对浏览器 UA 返回 412，非浏览器 UA 又拿不到网页里的 `__INITIAL_STATE__`，官方 extractor 能解析出封面但下不了流。
- **方案**：直接调用 B 站公开 API（`view` + `playurl`），接口请求用 curl UA + Origin/Referer，CDN 拉流用浏览器 UA；`try_look=1` 让游客拿到 720/1080；音视频分轨下载后用 FFmpeg 合并。

### 4.2 抖音（`douyin_adapter.py`）

- **问题**：`aweme/v1/web/aweme/detail` 自 2026-09 起被 Argus 风控接管，非浏览器请求一律 403；且 `jingxuan?modal_id=…` 精选页链接不在 yt-dlp 匹配表里。
- **方案**：用 Playwright（优先系统 Edge，`channel="msedge"`）真实打开视频页，由抖音自己的 JS 完成挑战、拿到带签名的 `aweme_detail`，提取各清晰度 `douyinvod` 合并流直链。H264 优先，ByteVC1/HEVC 标注兼容性提示。直链带时效签名，解析与下载各自重新取一次。

### 4.3 YouTube / TikTok（`site_profiles.py`）

- 有 `curl_cffi` 时使用 `ImpersonateTarget.from_str("chrome")` 做 TLS 指纹伪装。
- YouTube 无 cookies 时经常返回 bot check，是平台风控而非封装问题，留给后续 Cookies 注入（Pro）能力。

## 6. 遇到的问题与解决

1. **yt-dlp `impersonate` 断言错误**：`ImpersonateRequestHandler` 要求 `ImpersonateTarget` 对象而非字符串，`site_profiles.py` 改为 `ImpersonateTarget.from_str("chrome")`。
2. **B 站解析失败**：官方 extractor 受 WAF 影响，落地独立适配器走公开 API。
3. **抖音精选链接不支持**：链接格式不识别 + Argus 风控双重问题，落地 Playwright 浏览器方案解决。
4. **FFmpeg 子进程编码错误**：Windows 下 `subprocess.run` 默认文本模式触发 `UnicodeDecodeError`，改为 `capture_output=True`（不传 `text=True`）解决。

## 7. 当前状态与已知限制

- **可稳定下载**：哔哩哔哩、抖音、以及 yt-dlp 原生覆盖的公开站点。
- **受限**：YouTube 高清/稳定解析、需登录/会员内容，依赖 Cookies 注入（Pro 能力，MVP 未做上传 UI）。
- **部署依赖**：抖音适配需 Playwright；有系统 Edge 免装浏览器，纯 Linux 服务器需 `python -m playwright install chromium`。

## 8. 后续规划

按需求文档 4.2 的顺序推进：

1. **批量下载**：一次粘贴多条链接或解析整个合集
2. **Cookies 注入**：上传 `cookies.txt`，解锁 YouTube 高清与会员内容
3. **付费体系**：免费额度 + 激活码 + Pricing 页
4. **AI 视频总结**：抽字幕送大模型生成摘要
5. **字幕翻译**：下载/自动字幕翻译为 SRT

## 9. 维护要点

- 平台解析失效时，先 `pip install -U yt-dlp`，再考虑在 `site_profiles.py` 或新增 adapter。
- 不要修改 yt-dlp 源码，保持可升级性。
- 新增付费/额度在 `db.py` 加表、`routes.py` 入口拦截，勿污染 `ydl_service.py`。
